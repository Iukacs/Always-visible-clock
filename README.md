Always-visible-clock

A simple, always-visible desktop clock for Windows with a few useful features.

Features:
Always on top – stays visible even when using other applications or playing games.
Draggable – move it anywhere on your screen.
Customizable text color.
Adjustable font size.
Save clock position.
Reset all settings to default.
Automatically detects your Windows display language.

Font:
The clock works without any additional fonts, but for the intended digital clock look, I recommend DS-Digital.

You can download it separately here:
https://dl.dafont.com/dl/?f=ds_digital

The font is optional and is not included in this repository.

Supported languages:
English
Hungarian
German
French
Polish

The interface automatically detects your Windows display language. I haven't tested every language, so sorry if something doesn't work as expected!

Requirements:
Windows
AutoHotkey v2 (not required if using the compiled executable).
